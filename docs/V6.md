# V6：方法与运行

V6 使用一套策略处理圆形、方形和六边形插入。公开入口围绕两份 V6 配置组织；Python 包名与训练脚本名沿用原项目，以兼容现有检查点。

## 运行环境

本次整理在既有 Linux / Python 运行时核验以下版本。接触补丁会检查 MuJoCo Warp 的版本和上游文件哈希，升级依赖后需要重新验证。

| 依赖 | 已核验版本 |
|---|---|
| MJLab | 1.3.0 |
| MuJoCo / MuJoCo Warp | 3.7.0 / 3.7.0.1 |
| Warp | 1.12.0 |
| PyTorch | 2.14.0（本机 CUDA 13.0 构建） |
| NumPy / SciPy | 2.2.6 / 1.15.3 |
| RSL-RL / TensorDict | 5.0.1 / 0.14.0 |
| TensorBoard | 2.21.0 |

从仓库根目录执行 `python -m pip install -e .`。PyTorch 的 CUDA 构建需与本机驱动、硬件匹配；此项目尚未提供干净机器的一键运行镜像。模型资产按克隆目录定位，因此使用源码目录与 editable install。

运行器优先使用 `CONTACTFORGE_RUNTIME` 指定的虚拟环境，其次是仓库 `.venv`，最后使用当前 PATH 中的 Python；也兼容原 `MPHS_RUNTIME` 设置。

```bash
export CONTACTFORGE_RUNTIME=/absolute/path/to/compatible/venv
bash scripts/run_local.sh python scripts/blind_study_job.py --help
bash scripts/run_local.sh python -m unittest discover -s tests -v
```

测试不启动训练。GitHub Actions 的 `source checks` 只做语法、JSON 和发布源码来源校验，CPU 回归测试需在安装依赖后执行。

## 观测、网络和执行

| 部分 | V6 合同 |
|---|---|
| 单帧 Actor 观测 | 36 维：30 维本体信息 + 6 维补偿后的 F/T |
| 历史缓存 | 30 帧；最近 29 帧进入 TCN，策略周期 20 ms |
| 双流编码 | 本体 / F/T 各投影到 32 维，再逐元素相加 |
| TCN 输出与 Actor | 32 维历史特征 + 最新 36 维观测；Actor 隐层 256 / 256 / 128 |
| Contact 辅助头 | 64 个边界点 × 3 类几何标签 |
| Pose 辅助头 | 6 维相对位姿目标；对称周期处理 yaw，圆形屏蔽 yaw 损失 |
| Critic | 训练期特权状态；Actor 不读取 Critic、标签或位姿真值 |
| 动作 | 6 维，平移参考步长尺度 6 mm，旋转尺度 0.006 rad |
| 底层控制 | 1 kHz 笛卡尔参考跟踪、F/T 调节与主动卸载 |

动作是参考点的变化，不是保证实现的机械位移。F/T 是策略间隔均值；控制器滤波时间常数 5 ms。30 帧覆盖首末采样间隔 580 ms，29 帧 TCN 输入对应 560 ms。辅助头参与训练损失，动作前向路径不消费辅助头输出；当前检查点仍包含这些头。

轴载体的被动平移弹簧为 X/Y 各 6 N/mm、±2 mm，Z 为 4 N/mm、±4 mm。没有显式被动转动关节，也未完成实机柔顺标定。

## A / B 单阶段

| 参数 | A | B |
|---|---:|---:|
| 单边间隙 | 0.5 mm | 0.05 mm |
| seed | 7 | 17 |
| 学习率 | 3e-4 | 1e-4 |
| 环境数 × rollout 步数 | 12288 × 32 | 12288 × 32 |
| 默认新增更新 | 1000 | 1000 |
| 每阶段新增决策样本 | 393,216,000 | 393,216,000 |
| 检查点 / 评估 | 每 50 更新保存 / 仅最终评估 | 每 50 更新保存 / 仅最终评估 |

```bash
bash scripts/run_local.sh python scripts/blind_study_job.py \
  evaluation/my_A --config configs/blind_v6_cartesian_ft_A_05mm.json

bash scripts/run_local.sh python scripts/blind_study_job.py \
  evaluation/my_B --config configs/blind_v6_cartesian_ft_B_005mm.json \
  --initialize-from /absolute/path/to/A/checkpoint_00100.pt
```

`--initialize-from` 加载 Actor、Critic 与归一化状态，使用新优化器和新计数；`--resume` 属于底层 CLI 的完整续训接口。既有 A 的暂停状态属于原实验，不因新仓库整理而恢复。

### 使用原实验的 A100

原 A100 的配置记录了 `[200, 400, 600, 800, 1000]` 分段评估计划。本发布默认只最终评估，配置值为 `[1000]`。现有严格初始化合同也比较这个元数据字段，因此原 A100 不能直接配合默认 B JSON 启动。

保留原计划字段，并用启动器显式选择只最终评估；这样不需要改动或放宽核心训练校验：

```bash
mkdir -p evaluation
python - <<'PY'
import json
from pathlib import Path
cfg = json.loads(Path('configs/blind_v6_cartesian_ft_B_005mm.json').read_text())
cfg['job_evaluation_iterations'] = [200, 400, 600, 800, 1000]
with Path('evaluation/B_from_original_A100.json').open('x') as stream:
    json.dump(cfg, stream, indent=2)
PY
bash scripts/run_local.sh python scripts/blind_study_job.py \
  evaluation/my_B_from_original_A100 \
  --config evaluation/B_from_original_A100.json \
  --initialize-from /absolute/path/to/original/A/checkpoint_00100.pt \
  --eval-at-transitions
```

末尾 `--eval-at-transitions` 不跟中间评估节点，实际作业仍为 1000 更新后最终评估。发布核查已验证两份原权重的源码指纹、Actor / Critic 严格加载与 CPU 前向，以及上述初始化配置合同；没有追加 GPU 训练。

启动命令打印后台 worker PID。运行目录包含 `config.json`、`job.json`、`frozen/`、`status.json`、`training.log`、`training/`、`evaluation/` 与 `tensorboard/`。读取 `status.json` 判断完成或失败；不要仅凭 launcher 正常退出判断训练成功。

```bash
cat evaluation/my_B/status.json
bash scripts/run_local.sh tensorboard --logdir evaluation/my_B/tensorboard
```

### 小规模链路验证

正式配置占用较多 GPU 内存。需要验证新机器的执行链时，复制配置并设置小环境数，再显式限定预算。例如下面是 30 环境、32 步、1 次更新的独立试跑，其结果不代表正式成绩：

```bash
mkdir -p evaluation
python - <<'PY'
import json
from pathlib import Path
cfg = json.loads(Path('configs/blind_v6_cartesian_ft_A_05mm.json').read_text())
cfg.update(num_envs=30, reset_bank_size=120, minibatches=4,
           job_iterations=1, job_evaluation_iterations=[1])
with Path('evaluation/local_smoke_config.json').open('x') as stream:
    json.dump(cfg, stream, indent=2)
PY
bash scripts/run_local.sh python scripts/blind_study_job.py \
  evaluation/my_smoke --config evaluation/local_smoke_config.json \
  --transitions 960 --evaluation-per-shape 10
```

上述试跑会启动新训练。发布核查未执行它；每次换新配置文件名和输出目录，不覆盖历史结果。

## 独立评估

```bash
bash scripts/run_local.sh python scripts/blind_contact_ppo.py evaluate \
  evaluation/my_B_recheck \
  --config configs/blind_v6_cartesian_ft_B_005mm.json \
  --checkpoint /absolute/path/to/B/checkpoint_01000.pt \
  --num-envs 6144 --seed 10007
```

评估需要兼容 GPU 和可信的本项目检查点。原最终评估另将 `reset_bank_size` 设为 `6144 × 4`，严格重放应使用原运行的 `evaluation_config.json`、冻结源码及相同运行时；仅使用上述发布配置不能声称逐案例复现。始终使用新输出目录。

A100 与 B1000 会校验实现指纹；本发布保留其 23 个指纹文件的原字节。新增模块、改写空白或重新格式化核心文件也可能改变指纹，需要新实验版本与明确的迁移验证。

## 代码导航

核心目录：`src/mjlab_contact_prep/blind_contact/`。

| 模块 | 职责 |
|---|---|
| `cartesian_environment.py` | V6 观测、奖励、1 ms 终止与三形状工厂 |
| `cartesian_control.py` | 轴尖笛卡尔参考、F/T 卸载与关节阻抗执行 |
| `cartesian_networks.py` | 双流编码、TCN、Actor、辅助头 |
| `training.py` / `validation.py` | PPO、检查点、冻结来源和评估 |
| `seating.py` / `polygon_geometry.py` | 倒角、几何合法性与座深判据 |
| `wrench_sensor.py` | 接触约束行地址修正与版本校验 |
| `assets.py` / `passive_assets.py` | 三形状资产与被动弹簧 |

`environment.py`、`study_environment.py`、`polygon_environment.py`、`networks.py`、`control.py` 仍构成 V6 的基础类与公共函数。另有少量模块属于检查点指纹或兼容校验；不能仅按文件名或旧版本注释判断它们无用。
